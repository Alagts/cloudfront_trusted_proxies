============
Installation
============

Install the extension via Composer::

	composer require mfd/cloudfront-trusted-proxies

Requirements
============

* PHP ^8.3
* TYPO3 ^13.0 || ^14.0

After installation, the extension is active by default (see
:ref:`Configuration <configuration>` for how to disable it) — no database
updates or further setup steps are required.
